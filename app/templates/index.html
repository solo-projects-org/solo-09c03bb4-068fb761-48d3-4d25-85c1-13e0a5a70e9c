API 文档

上传补传记录

CSV 表头：事件号, 匿名卡号, 时刻, 站点, 方向, 修订号。 方向填 进站/出站 或 in/out；时刻为 UTC（带 Z 或偏移）。 一次最多两个连续 UTC 日；同事件号更高修订号会覆盖旧记录。

上传站点日完整清单

清单表头：事件号, 修订号（英文 event_no, revision 亦可）。 清单代表该站点该 UTC 日的全部刷卡事件；同一站点日再次上传会替换旧清单并立即撤回旧核收结论。

站点日核收

仅当清单、已受理刷卡、修订号三者完全一致时显示核齐；没有清单的站点日永不判为核齐。 待核期间重核失败或服务重启后，旧结论不会恢复。
